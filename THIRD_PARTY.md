# Third-party references and external tools

The included Python console uses the Python standard library. The node,
`yggdrasilctl`, Go configuration decoder, services and supporting executables
are external runtime integrations, not bundled dependencies or source in this
repository. Their authors retain their respective rights and licenses.

The atlas implements Yggdrasil address and remote-query semantics and was
checked against [upstream Yggdrasil](https://github.com/yggdrasil-network/yggdrasil-go),
which has its own LGPL-3.0 terms and special exception. The owner describes this
project's code as independently authored; a technical comparison found a
different Python expression of the address algorithm, but is not a legal
determination of authorship or derivative-work status. Do not infer upstream
endorsement or blanket rights to copy upstream code from this repository's MIT
license. Review provenance and applicable terms for any future addition.

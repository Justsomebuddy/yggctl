# Security policy

## Supported scope

This is experimental reference source. There is no supported stable release or
security-update SLA. Testing the source does not qualify a host deployment.
See [operational limitations](docs/SECURITY.md) before running commands.

## Reporting

Do not disclose credentials, private configuration or exploitable details in a
public issue or pull request. This staging repository does not yet advertise a
dedicated external reporting channel. Existing collaborators should use their
established private channel to the owner, Justsomebuddy, without copying secrets
into issue text or CI logs. No response time is promised.

Before public visibility, the owner must establish and document a private
reporting route. If GitHub private vulnerability reporting is enabled later,
use the repository's Security tab; do not assume it is currently enabled.
